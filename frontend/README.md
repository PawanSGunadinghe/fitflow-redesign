# FitFlow Mobile & Web Frontend

Cross-platform mobile application for **FitFlow**, built using **React Native**, **Expo SDK 51**, **TypeScript**, and **React Native Reanimated**.

## Key Modules & Screens

- **AI "Daily Flow" Recommendation Card**: Real-time adaptive workout generated from user telemetry, current energy levels, and previous workout recovery.
- **Interactive Workout Builder**: 60 FPS gesture-based drag-and-drop exercise customization.
- **Computer Vision Nutrition Scanner**: Camera-based instant meal recognition powered by OpenCV/YOLO microservice and USDA macro database.
- **Private Accountability Circles**: Real-time community challenges, cheering, and progress updates built for privacy and mutual motivation.

## Getting Started

```bash
# Install dependencies
npm install

# Start the Expo development server
npm start

# Run on iOS simulator
npm run ios

# Run on Android emulator
npm run android

# Run on Web browser
npm run web
```
